# Project Management Information System (PMIS)

Covers "evaluate project status" (artifact management) and supports "plan and manage communication."

## What it is

A PMIS is a set of software tools/systems that centralizes access to project-related information and
resources, facilitating communication, planning, and monitoring. It's the *tooling* layer underneath
plans like the Communication Management Plan (see
[communication-management.md](../people/communication-management.md)) — the plan defines what
information goes where; the PMIS is what actually moves and stores it.

## Common feature areas

Most PMIS software overlaps across these functions, though individual tools may specialize:

- **Scheduling and planning** (e.g. Primavera P6, Microsoft Project)
- **Team management and collaboration** (e.g. Slack, Microsoft Teams)
- **Budget and cost management** (e.g. ERP-style systems, QuickBooks-style accounting tools)
- **Work and performance control** (e.g. Kanban/task tools like Trello, ClickUp)
- **Documentation, data, and reporting** (e.g. BI/reporting tools, document management, BIM platforms
  in construction)

Some systems provide automated KPI tracking/reporting; others are primarily file storage. Some PMIS
platforms are general-purpose; others bundle industry-specific templates and features (e.g.
construction-specific tools like BIM coordination software).

## Exam framing

PMIS is a *tool/technique*, not a plan or a process itself — don't confuse it with the Communication
Management Plan or the Project Management Plan. When a scenario needs "a centralized system for
tracking and sharing project data," that's a PMIS question; when it needs "who gets what information,
how often," that's a Communication Management Plan question.
