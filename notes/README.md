# Notes

`notes.md` in this folder is one running, freeform capture page. Chelsea tells Claude to add to it as
she learns things ("add to notes: ...", "note that ...") and Claude appends the point under the
relevant domain heading — lightly organized, not rewritten wholesale.

This is deliberately separate from:
- `domains/` — the canonical, deduplicated study notes Claude builds by processing sources.
- `study-guide/guide.md` — Chelsea's own writing, hers alone to edit.

There is only ever one notes page. Don't create a second one.
