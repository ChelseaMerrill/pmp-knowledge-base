# Project Management Information System (PMIS)

Project Management Information System (PMIS) is a set of software tools or systems used to facilitate
project communication, planning, and monitoring by providing centralized access to project-related
information and resources.

There are various types of PMIS software, many of which offer similar features such as tools for data
collection, distribution, scheduling, and work authorization. Some systems also provide automated KPI
tracking and reporting, while others serve primarily as file storage solutions.

While some PMIS applications are suitable for any industry, others contain templates and features
tailored for specific industries. The following is an example of tools that could compose a PMIS in a
construction project, grouped by function:

- **Scheduling and Planning:** Primavera P6, Microsoft Project, Procore, Smartsheet, Excel
- **Team Management & Collaboration:** Fieldwire, Buildertrend, Slack, Microsoft Teams, WhatsApp,
  Basecamp
- **Manage Budget & Costs:** Procore, CMiC, Sage 300 Construction and Real Estate, Viewpoint Vista,
  SAP ERP, Oracle Primavera, Xero, QuickBooks
- **Control Work & Performance:** ClickUp, Trello, Autodesk Construction Cloud, eSUB Construction
  Software, Zoho Projects, Asana, Airtable
- **Documentation, Data, and Reporting:** Procore, Aconex, Autodesk BIM 360, Raken, Power BI, PlanGrid,
  Tableau, Bluebeam Revu, Google Workspace, Tekla/Trimble Connect
