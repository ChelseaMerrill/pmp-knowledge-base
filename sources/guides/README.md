# Study guides

For longer material — a study guide, an eBook excerpt, a set of course notes. One file per guide (or
per chapter/section if it's long enough that processing it in one pass would lose detail).

Name files `YYYY-MM-DD-short-title.md`. Template:

```markdown
---
type: guide
title: 
url: 
date_ingested: YYYY-MM-DD
domain: people | process | business-environment | mixed
status: raw
---

<!-- paste the guide text or your notes below -->
```

Once added, ask Claude to "process my new sources" (or name the file).
