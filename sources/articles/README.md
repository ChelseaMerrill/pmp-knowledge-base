# Articles

One file per article. Paste the URL and, ideally, the article text or your notes on it — Claude can
sometimes fetch a URL directly, but pasting the text guarantees nothing gets missed or paywalled.

Name files `YYYY-MM-DD-short-title.md`. Template:

```markdown
---
type: article
title: 
url: 
date_ingested: YYYY-MM-DD
domain: people | process | business-environment | mixed
status: raw
---

<!-- paste article text or your notes below -->
```

Once added, ask Claude to "process my new sources" (or name the file).
